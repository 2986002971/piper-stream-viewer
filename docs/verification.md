## 实际媒体与控制

TURN使用新生成的Piper X + D405场景，legacy relay使用外部完整场景。
两种模式均通过1920×1080连续视频120秒、主动断开、重连、刷新及正常停止清理。
检查连接中的PeerConnection、实时解码帧增长和视频停顿；人工检查控制前后截图确认机械臂可见且可信键鼠操作产生远端视角响应。
工具发出可信输入不等于控制成功，视觉证据需要人工检查。

Windows、macOS、Chromium及其他浏览器未做本轮媒体验收；标准库可移植性不代表跨平台媒体实测。
复用了现有GPU环境，未从空GPU操作系统全量重装。

历史50次延迟口径：TURN 50/50响应；relay 48/50响应、2次超时，主分位数只使用46个无迟到归属疑义样本。见[测量说明](diagnostics.md)。
短测不能推断长期可靠性。本机HTTP页面、WS信令、TCP媒体、Linux管理机SSH生命周期及75分钟watchdog仍适用。
统一托管、HTTPS/WSS与长期托管验收属于后续工作。
